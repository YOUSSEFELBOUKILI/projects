# Rock Paper Scissors

A simple command-line Rock, Paper, Scissors game against the computer. First to 3 wins takes the game.

## How to Play

```bash
python main.py
```

Type `rock`, `paper`, or `sieser` when prompted, and see if you can beat the AI!

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- First player to reach 3 points wins the game

## Requirements

- Python 3.x
